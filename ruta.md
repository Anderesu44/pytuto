## Parte 2

- Listas (arrays)
  - Creación y acceso a elementos
    - Indexado: [0], [-1]
    - Slicing: [start:end:step]
  - Métodos para listas
    - append(x): Agrega un elemento al final de la lista
    - insert(i, x): Inserta un elemento en una posición específica
    - remove(x): Elimina el primer elemento que coincida con x
    - pop([i]): Elimina y devuelve el elemento en la posición i (por defecto, el último)
    - clear(): Elimina todos los elementos de la lista
- Diccionarios (objetos)
  - Creación y acceso a elementos
    - Indexado: [key]
    - Slicing: [start:end:step]
  - Métodos para diccionarios
    - keys(), values(), items()
    - get(key, default): Devuelve el valor asociado a la clave si está presente, de lo contrario devuelve default
    - pop(key[, default]): Elimina y devuelve el elemento en la posición key (por defecto, el último)
    - clear(): Elimina todos los elementos del diccionario
- Tuplas (colecciones inmutables)
  - Creación y acceso a elementos
    - Indexado: [0], [-1]
    - Slicing: [start:end:step]
  - Métodos para tuplas
    - count(x): Devuelve el número de veces que x aparece en la lista
- Sets (colecciones sin orden)
  - Creación y acceso a elementos
    - Indexado: No se puede acceder directamente a los elementos por índice
    - Slicing: [start:end:step]
  - Métodos para sets
    - add(x): Agrega un elemento al conjunto
    - remove(x): Elimina el primer elemento que coincida con x
    - pop(): Elimina y devuelve un elemento aleatorio del conjunto
- Funciones de orden superior (Higher-order functions)
  - map(func, iterable)
  - filter(func, iterable)
  - reduce(func, iterable)
